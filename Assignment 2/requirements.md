# Password Reset Requirements

As a registered customer, I want to reset my password using a time-limited email link.
The link must expire after 15 minutes.
The link must not work after it has been used once.
The system should send a confirmation email after the password is changed.
The team is still deciding whether to support SMS fallback for users without email access.
The requirement is missing the exact error message to show when a link is expired or already used.
